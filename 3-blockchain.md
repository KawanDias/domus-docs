# 3. Blockchain Integration

## 3.1 Purpose of Blockchain

Blockchain is used as a **trust anchor**, providing:

- Imutability
- Transparency
- Verifiability

## 3.2 Hash-Based Storage Model

Instead of storing full data, DOMUS stores:

- SHA-256 hashes of transaction data

Example: 

Original Data → Hash → Stored on Blokchain

# 3.3 On-chain vs Off-chain

### Off-chain:
- Full transaction data
- User information
- Property details

### On-chain:
- Hashes only

- This reduces cost and preserves privacy.

## 3.4 Smart Contracts

A simple smart contract can be used to: 

- Register hashes
- Associate timestamps
- Allow public verification

# 3.5 Benefits

- Detect any data tampering
- Provide imutable proof of events
- Enable independet verification

## 3.6 Limitations

- Does not repalce legal property registration
- Requires integration with traditional systems
