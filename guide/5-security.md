# 5. Security 

## 5.1 Cryptographic Hashing

DOMUS uses hashing algorithms (e.g., SHA-256) to:

- Convert data into fixed-size strings
- Ensure uniqueness
- Detect modifications

## 5.2 Data Integrity 

Any change in original data results in a completely different hash, enabling detection of tampering.

## 5.3 Immutability 

Once stored on blockchain:

- Data cannot be altered
- Records are permanent

## 5.4 Transparency

Blockchain allows:

- Public verification
- Independent auditing

## 5.5 Fraud Prevention 

The system prevents:

- Document manipulation
- Unauthorized changes
- Fake transaction records

## 5.6 Security Model

DOMUS combines:

- Traditional backend security
- Blockchain-based validation

## 5.7 Limitations

- Does not prevent off-chain fraud
- Depends on correct data input
